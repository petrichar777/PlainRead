# 03 · 里程碑与验收清单

> 使用方式：每完成一项把 `[ ]` 改成 `[x]`。**验收标准是可执行的断言**，不是主观感受。
> 详细设计见 [02-架构设计.md](02-架构设计.md)。

---

## 优先级与顺序原则

两个排序决策值得先说明：

1. **安卓构建链在第 1 个里程碑就打通**（M0 末尾），而不是放到最后。
   > 理由：安卓交叉编译是唯一一个"环境问题可能连续几天定位不到"的环节。把它前置，最坏情况在项目第二天就暴露，而不是在第 N 周推倒重来。

2. **排版内核（M2）先于交互打磨（M3）**。
   > 理由：分页是阅读器的地基。地基歪了，翻页动画、书签定位、进度保存全都要返工。

## M0 · 工程骨架与构建链打穿

**目标**：两端都能跑起来，哪怕界面只有一个空窗口。**先把"能不能做出来"变成"已经做出来了"。**

### 交付物

- [ ] Cargo workspace 骨架，5 个 crate 目录就位，依赖版本锁定
- [ ] `reader-core` 领域模型定义完成（`Book` / `Chapter` / `ReadingProgress` / `Bookmark` / `ReaderSettings`）
- [ ] `reader-platform` 的 `Platform` trait 定义 + `DesktopPlatform` 实现 + `FakePlatform`（测试用）
- [ ] `app-desktop`：eframe 打开一个空窗口，标题正确
- [ ] `app-android`：`android_main` 入口 + Kotlin 壳 + Gradle 工程，能装到模拟器并显示空窗口
- [ ] `scripts/setup-android.sh` / `build-android.sh` 可用
- [ ] `rust-toolchain.toml` 与 `.cargo/config.toml` 就位

### 验收标准

- [ ] `cargo build --release -p app-desktop` 通过，双击 exe 出现窗口
- [ ] `cargo ndk -t arm64-v8a -t x86_64 --platform 26 -o android/app/src/main/jniLibs build --release` 通过
- [ ] `cd android && ./gradlew assembleDebug` 产出 APK
- [ ] APK 安装到模拟器后可启动，显示空窗口，**无黑屏、无闪退**
- [ ] `adb logcat` 能看到 Rust 侧日志输出（`android_logger` 已接好）
- [ ] `cargo test -p reader-core` 通过（此时至少有线上的模型序列化往返测试）

> ⚠️ **本里程碑的隐含验收**：搞清 Android 上的日志、调试、真机安装全链路。这是后续所有安卓工作的基础设施。

## M1 · 导入管线与书库

**目标**：能把 TXT 文件变成书架上的书，并且这本"书"的数据结构是正确的。

### 交付物

- [ ] `infra/encoding.rs`：BOM 检查 + `chardetng` 猜测 + `encoding_rs` 解码
- [ ] `infra/normalize.rs`：6 条规范化规则（见架构文档 §9.2）
- [ ] `infra/chapterize.rs`：L1–L4 四级章节切分 + 误判保护
- [ ] `infra/repo/`：redb 仓储（books / chapters / progress / bookmarks / settings 六张表）
- [ ] `infra/textfile.rs`：按 `start..end` 字节区间读取章节
- [ ] `app/library_service.rs`：导入用例编排（后台线程 + 进度回调）
- [ ] `reader-ui`：书架页（列表 / 网格自适应）+ 导入按钮 + 导入进度提示
- [ ] 测试语料 7 份（见架构文档 §12）入 `tests/assets/`

### 验收标准

- [ ] GBK 编码的 10 年前老 TXT 导入后**无乱码**，`source_encoding` 记录为 `GBK`
- [ ] UTF-8 / UTF-16LE(BOM) / GB18030 / Big5 样本全部解码正确
- [ ] 章节切分语料快照测试通过，`chapter_false_positive.txt` 中的"第一章"正文句**未被误判为标题**
- [ ] 切不出章节的文件走 L4 兜底，`has_real_chapters == false`，书架上有对应标识
- [ ] 重复导入同一文件时给出"疑似重复"提示（`content_hash` 命中）
- [ ] 导入 10 MB 长篇时，**峰值内存增量 < 100 MB**，UI 不冻结（有进度反馈）
- [ ] 删除书籍后，`books/<id>/` 目录与 redb 记录**同时**被清理
- [ ] `FakePlatform` 驱动的导入全链路集成测试通过

## M2 · 排版内核（最关键里程碑）

**目标**：一页纸上的字，位置、间距、换行全部由我们说了算。

### 交付物

- [ ] `infra/paginate.rs`：纯函数分页引擎（cosmic-text）
- [ ] `infra/layout_cache.rs`：内存 LRU + 磁盘缓存（key 含字体指纹）
- [ ] `reader-ui`：字形图集（`SwashCache` → `egui::TextureHandle`）+ Mesh 绘制
- [ ] `reader-ui`：字号 / 行距 / 字距 / 页边距 / 首行缩进 的实时调节
- [ ] `reader-ui`：三套主题（白 / 纸黄 / 夜间）
- [ ] 系统字体加载（`fontdb` 扫描系统目录 + 中文回退链）
- [ ] 进度保存与恢复（防抖落盘 + 恢复时二分定位）

### 验收标准

- [ ] **不变式 1（不丢字）**：`pages` 逐页切片拼接后**逐字符等于**规范化原文 —— 对全部测试语料成立
- [ ] **不变式 2（进度往返）**：`page_of(pages[i].start_char) == i` 对任意 `i` 成立
- [ ] 上述两条以 **property test** 形式存在并纳入 CI
- [ ] 分页函数在**无 GPU、无窗口**环境下可运行（`cargo test` 即可验证）
- [ ] 中文正文中，生僻字与繁体字**不出现方框/豆腐块**（字体回退生效）
- [ ] 拖动字号滑块后，页面重排**耗时 < 300 ms**（10 万字章节）
- [ ] 关闭应用再打开，**回到关闭时看到的那一句话**，误差 ≤ 1 行
- [ ] 改变窗口尺寸后进度不丢失（验证字符偏移方案的鲁棒性）
- [ ] 静止状态下 CPU 占用 ≈ 0（`request_repaint_after` 生效，可用任务管理器观察）

## M3 · 阅读体验

**目标**：从"能读"到"好读"。

### 交付物

- [ ] 翻页交互：点击三分区 + 左右滑动（可切换）
- [ ] 翻页动画：平移 + 淡入（约 180 ms）
- [ ] 章节内跨页 / 跨章翻页（含上下章预取）
- [ ] 目录页（章节列表 + 跳转 + 当前位置高亮）
- [ ] 书签（添加 / 删除 / 列表跳转）
- [ ] 设置页（字体、字号、行距、页边距、主题、翻页方式、常亮）
- [ ] 沉浸模式（全屏、点击中央呼出菜单）
- [ ] **中文标点禁则**（方案 A：插入 `U+2060` + 稀疏偏移映射）—— *可独立交付，不阻塞本里程碑其他项*

### 验收标准

- [ ] 目录页在 3000 章规模下**滚动流畅**（虚拟化列表生效）
- [ ] 目录跳转后进度条显示正确
- [ ] 书签的摘录内容与被加书签的位置**一致**
- [ ] 翻页动画无撕裂、无闪烁；快速连续翻页**不丢帧、不错位**
- [ ] 首章/末章边界翻页行为正确（不越界、不崩溃、有明确反馈）
- [ ] 禁则生效后：随机抽查 20 行，**行首无** `，。！？、；：）》」』】`，**行尾无** `（《「『【`
- [ ] 菜单呼出/隐藏不引起正文重排（菜单覆盖式或挤压式需二选一并明确）

## M4 · 安卓落地

**目标**：真机上"像那么回事"。

### 交付物

- [ ] `AndroidPlatform` 实现：数据目录、文件选择、安全区、系统字体、常亮
- [ ] 文件导入：`robius-file-picker` 接入（或自写 Kotlin SAF 桥兜底）
- [ ] `AndroidManifest.xml` 注册 `text/plain` 的 `VIEW` intent-filter
- [ ] 安全区适配：状态栏 / 挖孔 / 底部手势条 inset → 页面内边距
- [ ] 沉浸式全屏（`WindowInsetsControllerCompat`）
- [ ] 触摸手势映射（三分区、滑动、双指捏合调字号、长按加书签）
- [ ] 系统返回键处理（阅读页 → 书架 → 退出）
- [ ] 生命周期：`onPause` / `onStop` 立即落盘
- [ ] 应用图标（自适应图标 + 单色图层）与启动主题
- [ ] release 签名配置

### 验收标准

- [ ] 真机（非模拟器）安装并可正常阅读
- [ ] 从文件管理器"打开方式"导入 TXT 成功，**全程无权限弹窗**
- [ ] 从应用内按钮调起系统文档选择器导入成功
- [ ] **正文不被状态栏、挖孔、底部手势条遮挡或截断**
- [ ] 沉浸模式下系统栏完全隐藏，从边缘上滑可临时唤出
- [ ] 阅读时屏幕常亮；切到书架页后常亮**关闭**（不白耗电）
- [ ] 旋转屏幕后自动重排，**阅读位置不丢失**
- [ ] 双指捏合调字号后，阅读位置不丢失
- [ ] 系统返回键行为符合预期，无意外退出
- [ ] 按 Home 键切后台再回来，进度已保存
- [ ] 深色系统主题下，应用配色正确不刺眼
- [ ] APK 体积（arm64-v8a 单 ABI）**< 25 MB**

## M5 · 打磨与交付

**目标**：从"能用"到"可以给别人用"。

### 交付物

- [ ] 平板适配：按窗口宽度断点切换单栏 / 双栏与页边距档位
- [ ] 大书性能优化（10 MB 长篇：首开耗时、翻页耗时、内存占用）
- [ ] 错误处理：损坏文件、权限失败、磁盘写满、编码识别失败 → 友好提示而非崩溃
- [ ] 崩溃日志落盘（本地，不上传）
- [ ] 用户字体导入（`fonts/` 目录）
- [ ] 书籍重命名 / 手动分组（可选）
- [ ] 桌面端窗口尺寸与位置记忆
- [ ] README 使用说明 + 已知限制
- [ ] `armeabi-v7a` 补齐（若需要覆盖老设备）

### 验收标准

- [ ] 10 MB / 3000 章长篇：**首次打开到显示第一页 < 1.5 s**，翻页无感知延迟
- [ ] 连续翻页 200 次，内存占用**不增长**（无泄漏）
- [ ] 导入一个 0 字节 / 全是乱码 / 只有一行的文件，均**不崩溃**且有提示
- [ ] 低内存设备（模拟 2 GB）下长时间阅读不出 OOM
- [ ] 平板（横屏 10 寸）上正文字号与行宽**舒适可读**（单行不超过约 45 汉字，避免过长）
- [ ] 全部单元测试 + property test 通过
- [ ] 清理 `cargo clippy -- -D warnings` 零告警
