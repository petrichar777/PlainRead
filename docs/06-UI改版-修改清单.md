## 2. 两条工程约定（先立规矩，否则后面全乱）

**① 令牌沿用现有 `--ui-*` / `--rd-*` 前缀，只改值、只新增，不改名。**
设计稿里写的 `--c-canvas` / `--c-ink` 是稿内命名，落到代码一律映射到现有令牌（见 §5）。改名的代价是 200+ 处引用全部重写，收益为零。

**② 样式类名保留，只改实现。**
`.ui-btn-primary` 名字不变，内部从「黛青底」改成「墨底」。新增能力才加新类（`ui-rail-*` / `ui-book-*` / `ui-reg`）。这样 diff 可读、可回滚。

### 4.2-bis 书封精修（2026-10-18 复议，**覆盖 4.2 的形态**）

> 触发：P1 落地后实测偏"塑料感"。对比实验见 [design/书封方案对比.html](design/书封方案对比.html)。
> **结论：不建模、不做真 3D，改用「正视 + 竖直书脊 + 光照 + 纸质」的 2.5D 方案。**

**根因**：等轴测 `skew` 只能拼出平面平行四边形——书脊没有弧面、暗面是一整块色带、顶面靠 `brightness(1.22)` 提亮后变成灰白条，接缝处还会露出折角缺口。这是**方法论问题，不是参数问题**。

| 项 | 现实现 | 改为 |
|---|---|---|
| 书脊 | `skewY(-24.6deg)` 斜切 | **竖直 14px 窄条**，`border-left:1px` 书脊沟 |
| 顶面 | `skewX(65.4deg)` + brightness 1.22 | **删除**；改为封面顶部 2.4px「纸页切边」 |
| 封面圆角 | `0 2px 2px 0` | `2px 0 0 2px`（左侧也收 2px，右侧与书脊直拼） |
| 光照 | 两条叠层 | 四缘分别处理：顶缘受光 `.22` / 右缘背光 `.14` / 底缘压暗 `.22` / 斜向柔光 `.10` |
| 材质 | 无 | **可平铺纸纹**（`--ui-paper`，128×128 噪点 data URI，overlay 32%） |
| 书脊受光 | 纯色 ×0.74 | 三停渐变（暗–亮–暗）+ `saturate(.92)` |
| 阴影 | 单条 radial + blur 1.5px | **两层 box-shadow**：接触 `0 1px 2px /.22` + 散射 `0 6px 12px -6px /.30` |
| 书名位置 | 底部（`margin-bottom:auto` 把它推到下半） | **上半部起排**（`top:36px`），距书脊 22px |
| 节点数 | face / top / spine / shadow = 4 | face / spine = **2**（阴影与纸纹走伪元素，反而更少） |

**必守约束**

- 总宽仍是 **134px**（封面 120 + 书脊 14）→ `Shelf.tsx` 的列数测量、`--bw` 驱动逻辑**一行不改**
- `small` 模式（26px 列表缩略）依旧只渲染 face，不渲染书脊与纸纹
- 纸纹必须走 `background-image` + `mix-blend-mode: overlay`，**不得用 `filter` 做噪声**（会逐帧重算）
- 夜间主题下纸纹 `opacity` 从 .32 降到 .18（深色上 overlay 会过曝）

**新增令牌**

```
--ui-paper: url("data:image/svg+xml,…feTurbulence baseFrequency=.85…");
--ui-book-hi: rgb(255 255 255 / .22);   /* 顶缘受光 */
--ui-book-lo: rgb(0 0 0 / .22);         /* 底缘压暗 */
--ui-book-groove: rgb(0 0 0 / .28);     /* 书脊沟 */
```

**替代方案（已否决，记录理由）**

| 方案 | 否决理由 |
|---|---|
| Blender 建模 + 位图贴图 | 125%/150% 缩放下必糊；每本书颜色由书名 hash 生成、无法逐本渲染；夜间需另出一套 |
| CSS `preserve-3d` 真 3D | 18 本 × 3 个 3D 合成层滚动掉帧；书名随透视变形发虚；行内透视余量不同导致间距对不齐 |
| 内联 SVG 手绘书脊 | 可做贝塞尔弧面，质感最高，但 18 本 × 每本一套渐变 + 滤镜，节点数与栅格化成本不划算（若将来只做"继续阅读"大卡，可单独用） |

### 4.5 `code/src/App.tsx` + 新文件 `components/AppShell.tsx` / `components/Rail.tsx`

**结构变更（P2 核心）**

```
App
└─ ErrorBoundary
   └─ AppShell            ← 新增：负责桌面/移动骨架切换
      ├─ Rail             ← 新增：≥1024px 才渲染
```

| 项 | 规格 |

| 断点 | `1024px`；用 `useMediaQuery` hook（`matchMedia` + 监听），**不用纯 CSS 显隐**——两套 DOM 同时存在会出现两个「导入」按钮，可访问性不干净 |
