为什么不做"建模 + 贴图"

三条硬理由：① 缩放假象——Windows 常见的 125%/150% 缩放下位图封面必然发虚，而书架是长时间停留的界面；② 每本书颜色不同——TXT 没有封面，颜色由书名 hash 生成，位图要么逐本渲染（做不到），要么用 blend-mode 染色（会把阴影和纸纹一起染脏）；③ 主题切换——夜间要把封面整体压暗，位图得再出一套。

真要"建模一次、调用多次"，正确形态是 把书做成参数化组件：几何、光照、材质写成代码，颜色与书名作参数传入。方案 B 已经是这个形态——它"建好模"了，只是建模工具是 CSS 而不是 Blender。
