设计原则

① 内容即界面 —— 阅读态零常驻 UI ② 动效为因果服务，不做装饰 ③ 书卷气，不是科技感 ④ 高频操作触达 ≤ 2 步 ⑤ 双端同源，桌面 = 大号手机

完整定义见规范文档 §2。所有值最终落为 theme.css 的 CSS 变量，组件禁止裸色值。

① 书架 · 网格模式

TXT 无封面 → 书名首字 + hash 莫兰迪底色生成占位封面；点按直接进阅读页（无详情页中间层）；长按多选删除/重命名。

第一章 · 风起

暮春三月，草长莺飞。江南的雨总是来得没有预兆，前一还是晴空万里，这一便淅淅沥沥地落了下来，把青石板街洗得发亮。

沈砚之撑着一把油纸伞，站在渡口的茶棚下。他已经在这里站了半个时辰，目光始终落在江面上那艘缓缓靠岸的乌篷船上。

船头立着一个灰衣人，斗笠压得很低，看不清面目。船未靠稳，灰衣人便一跃上了岸，脚步极快，转眼便到了茶棚前。

"沈公子。"灰衣人摘下斗笠，露出一张风霜之色甚重的脸，"东西带来了。"

沈砚之不动声色地收了伞："进来说。"

茶棚深处，两人对坐。灰衣人从怀中取出一个油布包，层层揭开，里面是半页泛黄的残信。信上的字迹已经淡得几乎看不清了，只有落款处的一方朱印，红得刺眼。

"二十年了。"沈砚之的手指抚过那方朱印，声音很轻，像是在自言自语，"我以为这一辈子都等不到了。"

"大人说，当年之事，另有隐情。这半页信，只是个开头。"灰衣人压低了声音，"其余的，要您亲自去取。"

"去哪里取？"

"北边。"灰衣人顿了顿，"雁门关外。"

雨声忽然大了。棚外有马蹄声疾驰而过，溅起一路水花。沈砚之抬眼望去，那骑手一身玄衣，背后斜插着一杆小小的令旗——是节度使府的传令兵。

他把残信重新包好，贴身收了，然后从袖中摸出一锭银子放在桌上："辛苦。替我谢过大人。"

灰衣人却没有走："沈公子，还有一句话。大人说，信送到之日，就是您动身之时。京中的眼睛，已经盯上您了。"

沈砚之端起茶盏，茶已经凉了。他一饮而尽，站起身来，把银子推了过去："我知道了。"

他走出茶棚，雨还在下。江面上雾气渐起，远山如黛。他把油纸伞往肩上一搭，朝着与来路相反的方向，走进了雨里。

没有人注意到，茶棚角落里那个一直打瞌睡的跑堂，在他转身的那一刻，悄悄睁开了眼睛。
