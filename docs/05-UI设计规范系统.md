## 1. 设计原则（五条 + 一条例外）

| # | 原则 | 含义 | 反例（明确不做） |
|---|---|---|---|
| 1 | **内容即界面** | 阅读态正文之外的一切 UI 都要能"退场"，且默认退场 | 常驻悬浮按钮、常驻进度条 |
| 2 | **动效为因果服务** | 动画只表达空间关系与状态变化 | 图标弹跳、装饰性视差 |
| 3 | **书卷气，不是科技感** | 暖纸底、墨色字、朱砂点缀；克制安静 | 霓虹渐变、玻璃拟态堆砌 |
| 4 | **实用优先** | 每个交互都要能回答"它帮读者省了什么"；高频操作 ≤ 2 步 | 三级菜单里藏主题切换 |
| 5 | **双端同源** | 一套令牌；桌面端只做**密度与断点**差异 | 两套色彩/图标/动效体系 |

**例外（D1，2026-10-18 确认）**：原则 5 的"桌面端 = 大号手机端"允许**骨架层面**破例——
桌面端使用 236px 左侧栏（`Rail`），手机端不显示。**破的只有骨架，不破令牌**：
颜色、字体、圆角、动效、图标、组件行为全部同源。

## 2. 设计令牌

> 命名：阅读区 `--rd-*`，界面骨架 `--ui-*`。
> **护栏：组件里禁止裸色值 / 裸圆角 / 裸时长**，一切引用令牌（`main.css` 的 `:root` 与三套主题块）。
> 主题切换：`<html data-theme="paper" | "white" | "night">`，书架/目录/设置的 chrome 跟随阅读主题明暗。

### 2.3 阅读主题（三套）

| 令牌 | paper（默认） | white | night |
|---|---|---|---|
| `--rd-bg` | `#F4F0E6` | `#FDFCFA` | `#191919` |
| `--rd-fg` | `#2A2620` | `#1C1B18` | `#C6C2B9` |
| `--rd-muted` | `#A79E8C` | `#8E8A81` | `#7A766E` |

### 2.4 字体

| 令牌 | 栈 | 用途 |
|---|---|---|
| `--ui-font` | `system-ui, "Segoe UI", "Microsoft YaHei", …` | 全部 UI 文字 |
| `--ui-font-serif` | `"Source Han Serif SC", "Noto Serif SC", Georgia, "宋体", serif` | 正文默认、书封书名、章标题 |
| `--ui-font-mono` | `ui-monospace, "Cascadia Mono", "Consolas", …` | 档案编号、章次、百分比、阶段 |

- UI 与正文**字体分离**：界面无衬线保证锐利，正文衬线给"书"的质感。
- **不内置字体文件**（体积 + 授权），回退交给浏览器——架构决策，设计层遵守。
- 正文可在设置里切「衬线 / 黑体」两档（`--rd-font-family`）。

### 2.5 字号阶梯

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ui-text-xs` | 11px | 页码、时间戳 |
| `--ui-text-sm` | 13px | 辅助文字、列表副标题 |
| `--ui-text-base` | 15px | 列表主文字 |
| `--ui-text-lg` | 17px | 继续阅读卡书名 |
| `--ui-text-xl` | 20px | 次级标题 |
| `--ui-text-2xl` / `3xl` | 28 / 34px | 页面主标题（桌面 34，窄屏 28） |

字重只有 400 / 500 / 600 / 700 / 800 五档，**800 只用于页面主标题**，600 用于强调与当前项。
主标题字距 `-1.1px`（大字号需要负字距才不散）。

**正文字号**：14–28px 可调，默认 **20px / 行高 1.95 / 段距 0.55em**（桌面 620 列宽 ≈ 31 字/行，D5）。

### 2.6 圆角 / 间距 / 层级 / 动效

| 类别 | 令牌 | 值 |
|---|---|---|
| 圆角 | `--ui-radius-sm/md/lg/xl` | **2 / 3 / 4 / 6 px**；`--ui-radius-book` = 3px |
| 间距 | 4pt 基网格 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 浮层层级 | `--ui-e-pop` | `0 18px 44px -24px rgb(42 38 32/.45)`；夜间降级为 `0 0 0 1px var(--ui-border)` |
| 按键 | `--ui-dur-fast` | 120ms |
| 悬停 | `--ui-dur-hover` | 180ms |
| 翻页 | `--ui-dur-page` | 220ms |
| 面板 | `--ui-dur-panel` | 280ms |
| 主题切换 | `--ui-dur-theme` | 300ms linear |

规则：
- **卡片没有阴影**（v1 的 e1 已删除）——档案感来自纸与线，不来自投影；阴影只给"浮起来的东西"（dock / 面板 / Toast）。
- 夜间一律**描边替代阴影**（令牌内实现，组件无感）。
- 动画只动 `transform` / `opacity`；`prefers-reduced-motion: reduce` 时全局降到 80ms。

### 2.7 书封令牌（2.5D，§4.2-bis）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ui-cover-1…6-a/-b` | 六组低饱和莫兰迪起止色 | 封面底色（`-b` 兼作书脊底色） |
| `--ui-cover-1…6` | `linear-gradient(150deg, a, b)` | 单条渐变别名（列表缩略、继续阅读卡） |

| `--ui-book-sheen` | 白 `.10` | 斜向柔光 |
| `--ui-book-pages` | 竖向细条纹 `repeating-linear-gradient` | 封面顶部 2.4px 纸页叠层 |
| `--ui-book-arc` | 暗–亮–暗三停 | 书脊弧面（替代 `filter:brightness`） |

## 3. 四屏规格

> 四屏结构即 README 的"纯净版"约束：书架 / 阅读 / 目录 / 设置，不做第五屏。

### 3.1 书架

```
┌─ Rail 236 ─┬─────────────── 主区 ────────────────┐
│ 品牌        │ SHELF / 42 VOL. · SORTED BY LAST READ│ ← 页头：kicker + 34px 标题
│ 书架 42     │ 书架            [搜索][视图][导入]   │
│ 设置        ├──────────────────────────────────────┤
│ RECENT ×3   │ 继续阅读 ▢ 书名 CH.31/46 ▬▬ 68% 打开 │
│ INDEX 2×2   ├──────────────────────────────────────┤
│ 版本 / 诊断 │  ▮▮ ▮▮ ▮▮ ▮▮ ▮▮ ▮▮                  │ ← 书墙 6 列
│             │ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬       │ ← 贯通搁板
└─────────────┴──────────────────────────────────────┘
```

- **书墙**：每行 = 一组书 + 一根贯通搁板；书间 26px、行距 26px；内容栏 936px 居中；桌面左右留白 94px。
- **书封**：`docs/06 §4.2-bis` 的 2.5D——正视封面 120 + 竖直书脊 14 = 134，纸纹 + 四缘光照。
  **封面外不挂任何文字**（D3），书名印在封面上，读屏靠 `aria-label`。
- **继续阅读卡**：只在"读过且没读完"时出现；章节号由进度百分比反推（**近似值**，只用于文案）。
- **多选**：长按 500ms / 右键进入；卡片左上 18×18 方框 + 封面压暗 12%；顶部栏变「已选 N 本」+ 三个 34px 图标钮。
- **列表视图**：52px 行、无卡片无阴影、只有分隔线；左 26×36 缩略，中书名 + `WJ-xxxxxx · N CH.`，右 60px 进度条 + 等宽百分比。
- **三态**：骨架（300ms 后出现，立体书形状 + 空搁板）/ 空态 / 错误态（带重试）。

### 3.2 阅读页

```
┌──────────────────────────────────────────────────┬────────┐
│ ← 书名 CH.8/42                     [目录][排版]   │ 目录    │ ← 顶栏为浮层
│        CHAPTER 008                               │ 01 …    │
│        春神湖上                                   │ 08 当前 │ ← 320px 右栏
│        ─────                                     │ 09 …    │
│  风从长街尽头卷过来，带着雪粒和铁锈的味道。         │         │
│  他把手拢进袖子里，慢慢往前走。                     │         │
│                                     1 / 5        │         │ ← 页码右下
│        ▬▬▬▬ 19% ◯◯◯ A− 20 A+                     │         │ ← dock 560×56
└──────────────────────────────────────────────────┴────────┘
```

- **正文列宽 620px 是硬上限**：限宽只加在 `.reader-stage`，**绝不能**加在 `.reader-content`
  （多列布局的列宽由 `column-width` 决定，给内容限宽会让列内出现空档、分页错乱）。
- **顶栏与 dock 是浮层**，不占布局高度——chrome 显隐不会改变正文列高、不触发重排。
  鼠标进入顶部 80px 淡入、离开 1.2s 淡出；点击中央切换。
- **页码**在右下角，属"排版"不属于"UI"，常驻可见。
- **目录右栏**：≥1024px 为常驻右栏（Ctrl+B 开合）；**窄于此则改为浮层抽屉**——
  窗口放不下 320 + 620 时，挤压正文列宽会触发 Chromium 分栏重排不彻底的问题。
- **阅读设置**（`.ui-prefs`）：字号 / 行距 / 段距 / 页边距 / 字体，即改即生效，200ms 后按字符锚点归位。
- **位置永不存页码**：进度 = 章节号 + 章内字符偏移（锚点算法，架构 §5.1）。

### 3.3 目录

- 桌面常驻右栏 320px；窄屏浮层抽屉（占满宽度）。
- 列表项 38px：编号（等宽）+ 章名（1 行省略）；已读退成辅助色；
  **当前章三重信号**：朱砂左条 + 淡朱砂底 + 编号变朱砂。
- 3000 章必须虚拟滚动（只渲染可视区 ±20 行）。

### 3.4 设置

| 层级 | 入口 | 内容 | 持久化 |
|---|---|---|---|
| **阅读设置面板** | 阅读页顶栏 → 排版 | 字号 / 行距 / 段距 / 页边距 / 字体，**全部即时预览** | localStorage（每书覆盖留待契约扩展） |
| **全局设置页** | 侧栏 → 设置 | 外观（主题）、关于、诊断入口 | 主题记忆在 localStorage |

> 1.0 的"设置"实际落在诊断页（`Diagnostics`）：外观 + 自检 + IPC 往返测试。
> 侧栏「设置」与底部小字「诊断」暂时指向同一页，等全局设置页落地再分叉。

## 4. 组件规格

| 组件 | 关键规格 |
|---|---|
| Button | 主 `--ui-ink` 底 / 奶白字 / 3px 圆角 / 34px（紧凑）或 40px（大）；hover 换 `--ui-ink-hover`；active `scale(.985)` 120ms |
| IconButton | 视觉 34px，`::after inset:-5px` 把热区扩到 44px；hover 出 `--ui-hover` |
| BookCover | 见 §2.7：face + spine 两个节点；`small`（26px）只渲染 face |
| BookCard | 网格：只有封面，`aria-label` 承担可访问名，悬停上浮 4px；列表：52px 行 |
| Segmented | 34px 高，选中 = 墨底奶白字，**无滑动动画** |
| Search | 262px / 34px，focus 时四角出现 7px L 形套准线（签名交互）；`Ctrl K` 聚焦 |
| TocItem | 38px，当前章三重信号（见 §3.3） |
| Dock | 560×56 浮层，`bottom:20px`；进度滑杆 + 百分比 + 主题三圆 + A± |
| Prefs | 标签 52 / 控件中 / 数值右 52 等宽；滑杆轨道 2px、方形滑块 14px |
| Toast | 墨底奶白字 + 3px 圆角，3s 自动消失，同时最多 1 个 |
| Dialog | 只用于不可逆操作；遮罩 `--ui-scrim`；按钮 40px；确认按钮用 `--ui-danger` |
| EmptyState | 虚线方框 + 四角套准线；衬线标题；主按钮 40px；说明压到 1 行 |
| ThemeDots | 三个圆（色票不是按钮）；设置面板 28px，dock 18px；勾保留 |
| Skeleton | 书架首载 300ms 后出现；几何与真实书墙同构 |

### 4.1 图标规范（硬性规定）

> **禁止使用 emoji 充当图标，必须使用图标库图标。**（2026-10-09 用户确认）

| 项 | 规定 |
|---|---|
| 图标库 | **Lucide**（ISC，无署名义务；shadcn/ui 默认） |
| 风格 | 线性 24×24 网格、`stroke-width: 2`、圆角端点；**禁止混用第二套图标库** |
| 封装 | 统一走 `lucide-react`，禁止手写内联 SVG path 散落在业务组件里 |
| 尺寸 | 16（行内）/ 18（按钮内）/ 20（独立图标钮） |
| 颜色 | 一律 `currentColor`；需要强调时改父级文字令牌 |

常用映射：目录 `list` / 设置 `sliders-horizontal` / 返回 `chevron-left` / 导入 `book-plus` /
网格 `layout-grid` / 列表 `list` / 重命名 `pen-line` / 删除 `trash-2` / 关闭 `x` / 确认 `check`。

禁 emoji 的理由：跨平台字形不一致、无法随主题着色、与线性图标风格冲突——三条对"双端同源 + 三主题"全是硬伤。

## 5. 桌面骨架（D1）

```
App → ErrorBoundary → AppShell ─┬─ Rail（≥1024px 才渲染）
                                └─ {Shelf | Diagnostics}
Reader 不套 Shell（沉浸）
```

| 项 | 规格 |
|---|---|
| 断点 | 1024px，用 `useMediaQuery`（matchMedia + `useSyncExternalStore`）在 **JS** 里判定 |
| 为什么不纯 CSS | 两套 DOM 同时存在会出现两个「导入」按钮，读屏与 Tab 顺序都会撞车 |
| 侧栏 | 236px：品牌块 / 书架·设置 / RECENT 3 条 / INDEX 2×2 / 版本 + INDEX UPDATED + 诊断 |
| 统计口径 | 册数、在读（0<p<99）、已读完（p≥99）、未读（p==null）——无体积字段，故不用「GB 占用」 |
| 内容栏 | `.ui-page`：max-width 936 + 居中；页头 / 继续阅读 / 书墙共用它，左右边缘天然对齐 |

## 7. 无障碍基线（WCAG AA）

| 项 | 规格 |
|---|---|
| 对比度 | 正文/按钮字 ≥ 4.5:1；`--ui-text-3` 与 `--rd-muted` **不得用于可交互文字** |
| 焦点可见 | `:focus-visible` 2px `--ui-ink` 外描边（夜间自动变亮） |
| 触控目标 | 视觉可 34px，但热区必须 ≥ 44×44（`::after` 扩张） |
| 可访问名 | 书卡去掉外部标题后**必须** `aria-label`，否则读屏只剩"按钮" |
| 减弱动效 | `prefers-reduced-motion` 全局降级 |
| 语义 | 菜单/抽屉/dialog 用 ARIA role；正文容器 `aria-live="polite"` 只播报页码 |

## 9. 设计决策速查

| 问题 | 决策 | 一句话理由 |
|---|---|---|
| 品牌色 | **墨 + 朱砂** | 单色体系最耐看；朱砂只标"你在这里" |
| 卡片阴影 | **不用** | 档案感来自纸与线；阴影一多就变成"卡片堆" |
| 圆角 | 2 / 3 / 4 / 6 | 近直角才像档案，圆角是"消费级产品"的语法 |
| 封面 | 书名 hash 生成 + 2.5D 纸感 | TXT 无封面；灰块阵列是市面阅读器最丑的通病 |
| 书封要不要真 3D | **不要** | skew 拼出的平行四边形是方法论错误；`preserve-3d` 在 18 本时掉帧、文字发虚 |
| 桌面骨架 | 236px 侧栏（破原则 5 的骨架部分） | 1440 下顶部单栏会让 60% 屏幕成为空白 |
| 正文列宽 | 620px | 一行 70–80 字会换行丢行，是阅读体验最致命的细节 |
| chrome 形态 | 顶栏与 dock 都是浮层 | 占布局高度会让 chrome 显隐触发重排、页数跳变 |
| 目录窄屏 | 改浮层抽屉 | 挤压正文列宽会踩 Chromium 分栏重排不彻底的坑 |
| 夜间阴影 | 描边替代 | 深色下阴影不可见，描边是唯一正确的层级表达 |
| 图标 | Lucide，禁 emoji | 跨平台一致、可随主题着色、与 shadcn 生态同源 |
