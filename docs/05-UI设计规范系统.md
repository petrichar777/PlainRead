# 05 · UI 设计规范系统（简阅 · PlainRead Design System v1）

> 前置阅读：[02-架构设计.md](02-架构设计.md)（本文档所有令牌最终落为 `src/styles/theme.css` 的 CSS 变量）。
> 配套草图：[design/设计草图-交互演示.html](design/设计草图-交互演示.html)——含五屏静态稿与一台**可真实翻页、换主题、调字号**的演示机（演示机的分页实现即架构 §7.1 的 CSS 多列方案）。
> 设计目标：**比市面阅读器好看、交互更顺，但每个设计决策都必须服务于"读得进去"**。

---

## 1. 设计原则（五条，冲突时按序裁决）

| # | 原则 | 含义 | 反例（明确不做） |
|---|---|---|---|
| 1 | **内容即界面** | 阅读态正文之外的一切 UI 都要能"退场"，且默认退场 | 常驻悬浮按钮、常驻进度条 |
| 2 | **动效为因果服务** | 动画只用于表达空间关系（页面从哪来）、状态变化（菜单从哪弹出）；不做装饰性动画 | 图标弹跳、无意义视差 |
| 3 | **书卷气，不是科技感** | 暖纸色底、墨色字、朱砂点缀；克制、安静 | 霓虹渐变、玻璃拟态堆砌 |
| 4 | **实用优先** | 每个交互必须能回答"它帮读者省了什么"；高频操作触达 ≤ 2 步 | 三级菜单里藏主题切换 |
| 5 | **双端同源** | 一套令牌；桌面端 = 大号手机端，只做密度与断点差异，不另造桌面语言 | 桌面侧边栏 + 手机底部栏两套范式 |

## 2. 设计令牌（Design Tokens）

> 命名约定：阅读区令牌 `--rd-*`（与架构文档 §7.5 一致，不改动）；界面骨架令牌 `--ui-*`（本文档新增）。
> 所有令牌定义在 `theme.css`，Tailwind 4 通过 `@theme` 映射，组件只引用变量、不写裸色值。

### 2.1 品牌色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ui-primary-500` | `#2E6B5A` 黛青 | 主操作、选中态、进度 |
| `--ui-primary-600` | `#265649` | primary hover / pressed |
| `--ui-primary-100` | `#D7EAE3` | primary 弱底（选中章节底色等） |
| `--ui-accent-500` | `#C2554D` 朱砂 | 书签、高亮点缀、当前章指示条 |
| `--ui-accent-100` | `#F6E3E1` | 朱砂弱底 |

> 判词：市面阅读器多用蓝（微信读书）或红（起点）。黛青有"墨"的联想又不老气；朱砂只做点睛（书签、当前位置），大面积不出现——**大面积的强调色是廉价感的来源**。

### 2.2 阅读主题（三套，沿用架构 §7.5 并扩展）

| 令牌 | 纸黄 `paper`（默认） | 白 `white` | 夜间 `night` |
|---|---|---|---|
| `--rd-bg` | `#F5EFE1` | `#FFFFFF` | `#121212` |
| `--rd-fg` | `#2F2A22` | `#1A1A1A` | `#B8B4AD` |
| `--rd-muted` | `#8A8272` | `#8A8A8A` | `#6B6862` |
| `--rd-line`（分隔线） | `#E4DCC8` | `#ECECEC` | `#2A2A2A` |
| `--rd-selection`（长按选中底） | `rgba(194,85,77,.18)` | `rgba(194,85,77,.15)` | `rgba(194,85,77,.30)` |

对比度核对（WCAG AA）：正文三组均 ≥ 8:1 ✅；`--rd-muted` 约 3.2:1，**只允许用于页码、章节名等辅助信息**（大字号/非关键路径），不允许用于任何可交互文字。

> 夜间主题是**深灰不是纯黑**：`#121212` 在 OLED 上省电且不给文字镶白边；正文用 `#B8B4AD` 暖灰而非纯白，降低夜间刺眼度（对应里程碑 M4 验收"深色系统主题下不刺眼"）。

### 2.3 界面骨架色（随主题联动）

| 令牌 | 浅色 chrome | 夜间 chrome |
|---|---|---|
| `--ui-surface` | `#FBF8F0` | `#1A1A1A` |
| `--ui-surface-2`（卡片/面板） | `#FFFFFF` | `#242424` |
| `--ui-border` | `#E8E2D2` | `#333333` |
| `--ui-text-1` | `#2B2B26` | `#E4E1DA` |
| `--ui-text-2` | `#7A776D` | `#8F8C85` |

> 书架/目录/设置的 chrome 跟随当前阅读主题明暗：选了夜间主题，书架也是夜间的。**不做"阅读页夜间、书架白色"的割裂感**。

### 2.4 字体

| 令牌 | 栈 | 用途 |
|---|---|---|
| `--ui-font` | `system-ui, "Segoe UI", "Microsoft YaHei", sans-serif` | 全部 UI 骨架文字 |
| `--rd-font-family` | 用户可选：默认 `Georgia, "Times New Roman", "宋体", serif`；备选黑体、用户导入字体 | 仅正文 |

要点：
- UI 与正文**字体分离**：界面用系统无衬线保证锐利，正文默认衬线给"书"的质感，两键即换。
- 不内置字体文件（APK 体积 + 授权，见可行性 §3），回退交给浏览器——这条是架构决策，设计层遵守。

### 2.5 字号阶梯（UI）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ui-text-xs` | 11px | 页码、时间戳 |
| `--ui-text-sm` | 13px | 辅助文字、列表副标题 |
| `--ui-text-base` | 15px | 列表主文字、按钮 |
| `--ui-text-lg` | 17px | 章节标题（目录） |
| `--ui-text-xl` | 20px | 页面标题 |
| 字重 | 400 / 500 / 600 | 仅三档，600 只用于页面标题 |

**正文字号**（用户可调）：14–28px 滑杆，步进 1；默认手机 19px / 平板 21px / 桌面 20px。改动即时生效且**不丢阅读位置**（锚点算法保证，见架构 §7.3）。

### 2.6 间距 / 圆角 / 层级

| 类别 | 令牌 | 值 |
|---|---|---|
| 间距（4pt 基网格） | `--ui-space-1…16` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 圆角 | `--ui-radius-sm/md/lg/xl` | 6 / 10 / 16 / 24px；书封 8px；底部面板顶角 20px |
| 阴影 | `--ui-e1/e2/e3` | e1 卡片 `0 1px 3px rgb(0 0 0/.06)`；e2 菜单/面板 `0 8px 24px rgb(0 0 0/.12)`；e3 Toast `0 12px 32px rgb(0 0 0/.18)` |

> 夜间主题下阴影几乎不可见：**e1–e3 在夜间自动替换为 1px `--ui-border` 描边**（令牌内实现，组件无感）。这是"双端同源"令牌系统的价值之一。

### 2.7 动效令牌

| 令牌 | 时长 | 缓动 | 用途 |
|---|---|---|---|
| `--ui-dur-fast` | 120ms | `cubic-bezier(.2,0,0,1)` | 按压反馈、图标态切换 |
| `--ui-dur-page` | 220ms | `cubic-bezier(.25,.1,.25,1)` | **翻页平移/覆盖**（架构 §7.4 的 180–220ms 取上限，观感更从容） |
| `--ui-dur-panel` | 280ms | `cubic-bezier(.2,0,0,1)` | 菜单/面板/抽屉滑入滑出 |
| `--ui-dur-theme` | 300ms | linear | 主题切换整屏 crossfade |

规则：
- 快速连续翻页时，动画时长自动压缩到 **120ms**（第二次翻页打断第一次，从当前位置继续而非跳回起点）——保证"连点不卡"（M3 验收项）。
- `prefers-reduced-motion: reduce` 时，翻页与面板动画降为 80ms 淡入淡出。
- 动画一律只动 `transform` / `opacity`，禁止触发重排的属性（与架构"翻页 < 50ms"的验收一致）。

## 3. 四屏设计规格

> 四屏结构即 README 的"纯净版"约束：书架 / 阅读 / 目录 / 设置，不做第五屏。

### 3.1 书架

```
┌──────────────────────────┐
│ 书架                ⬆导入 │  ← 顶部栏 56px，标题左对齐，导入为主按钮
│                          │
│ ┌────┐ ┌────┐ ┌────┐     │  ← 网格 3 列（手机竖屏）
│ │封面│ │封面│ │封面│     │     平板/桌面横屏 4–6 列（自动断点）
│ │书名│ │书名│ │书名│     │
│ │进度│ │进度│ │进度│     │  ← 封面下两行：书名 1 行截断 + 进度百分比
│ └────┘ └────┘ └────┘     │
│ ···                      │
└──────────────────────────┘
```

- **封面**：无封面文件（TXT 天然没有），用"生成式占位封面"——书名首字大号衬线字 + 从书名 hash 出的 6 组莫兰迪底色循环。**不用同一色灰块**，书架才有"一排书"的观感。
- **排序**：按 `last_read_at`（契约已定），最近阅读在首位并带"继续阅读 · 剩余 x%"副标题。
- **列表 ↔ 网格**切换：顶栏图标，双态记忆。
- **书墙式排布（2026-10-11 owner 确认，网格模式由"纯网格"升级而来）**：每行书立于一根
  **贯通的搁板**上（`ui-plank`：上亮下暗暖纸渐变 + 极浅落影，`--ui-plank-*` 令牌随主题联动，
  夜间经 `--ui-e1` 自动换成描边），3–6 列自适应（104px 下限，ResizeObserver 测量），
  整体居中限宽（max-w-3xl），纵向滚动——微信读书的空间结构，更有"一墙书"的意境。
  列表模式保留为工具型视图；骨架屏同构（空搁板形态，加载时"书架就已经在了"）。
- **交互**：点按 = 直接进阅读页（**不经过详情页**——1.0 没有详情可看，少一层就是实用）；长按 = 多选模式（删除/重命名）；下拉无刷新动作（本地应用不需要）。
- **空状态**：居中一本"虚线封面"+「导入你的第一本书」按钮 + 一行说明支持从系统"打开方式"导入。
- **导入中**：被导入书显示为占位封面 + 环形进度（消费 `import://progress` 事件）。

### 3.2 阅读页（产品的心脏）

```
┌──────────────────────────┐
│ （沉浸：无任何常驻 UI）      │
│  第一章 风起               │  ← 章节标题随正文排版，不悬浮
│  正文……                   │
│  正文……                   │
│                 12 / 34   │  ← 页码右下角，muted 色，属"排版"不属于"UI"
└──────────────────────────┘
```

- **点击三分区**：左 30% 上一页 / 中 40% 呼出菜单 / 右 30% 下一页；设置内可切换为"点击两侧翻页、仅菜单键呼出"。
- **滑动翻页**：水平位移 > 60px 或速度 > 0.3px/ms 触发，手指跟随拖拽（1:1 跟手），松手按速度+位移判定落点——**跟手是"交互强"的核心体验**，市面大量阅读器只有固定时长动画。
- **菜单呼出**（点中央）：顶部条（返回、书名、章节名）+ 底部条（主题三圆、进度滑杆、目录、设置、书签）同时滑入，正文**不重排不缩放**（菜单为覆盖层，M3 验收项）。
- **进度滑杆**：拖动时实时显示目标章节名气泡，松手跳转；滑杆映射到字符偏移（不是页码，与锚点体系一致）。
- **书签**：阅读中长按 ≥ 400ms 任意位置 → 弹出"添加书签"胶囊（含当前句摘录预览）；已有书签的页面页脚出现朱砂小角标。
- **边界反馈**：首/末页继续翻页时整页做 8px 回弹 + 轻震动（安卓 `HapticFeedback`，桌面无），不弹 Toast 打断。
- **降级提示**：单章 > 2 万字自动切滚动模式时，用底部 Toast 说明"本章过长，已切换为滚动"，3s 自动消失。

### 3.3 目录

- **形态**：阅读页内从左侧滑出的抽屉（手机占屏宽 82%，桌面 380px 定宽），背景压暗 40%。
- **结构**：顶部书名 + 进度摘要；列表项 = 章节标题（最多 1 行省略）；当前章 **朱砂左指示条 + primary-100 底色**。
- **性能**：3000 章虚拟滚动（架构既定），抽屉滑入动画期间不渲染全量 DOM。
- **附加**：书签 tab 与章节 tab 同栏切换（1.0 不做两个入口）。

### 3.4 设置

两个层级，**职责不同**：

| 层级 | 入口 | 内容 | 持久化 |
|---|---|---|---|
| **阅读设置面板** | 阅读页菜单 → 设置 | 字号/行距/字距/边距滑杆、主题、翻页方式、字体——**全部即时预览**（面板半透明，能看见后面正文变化） | 每书覆盖（契约 `ReaderSettings` 已合并） |
| **全局设置页** | 书架 → 设置 | 阅读默认值、常亮、翻页动画开关、关于 | 全局默认 |

- **滑杆规范**：拖动中显示数值气泡；松手才 `save_settings`（前端防抖，契约既定）；拖动过程用 rAF 节流重排（架构 §7.4）。
- **主题选择**：三个圆形色票（纸黄/白/夜间）横排，当前项带描边——比下拉列表快一倍。
- **设置面板滑入**：底部 sheet 280ms，正文页同步缩小 2% + 压暗（给出"设置了层"的空间感，收起还原）。

## 4. 组件库规范

> 组件基于 shadcn/ui 定制皮肤，全部消费 §2 令牌。以下列出**行为规格**，视觉规格见草图。

| 组件 | 变体 | 关键行为规格 |
|---|---|---|
| Button | primary / tonal / ghost / icon | 高度 44px（触控下限）；icon 按钮 44×44；按压 scale(0.97) 120ms |
| BookCard | grid / list | 封面比例 3:4；按下 scale(0.98) + e1→e2 阴影上浮 |
| Slider | 数值气泡 | 轨道 4px、滑块 20px；拖动中 rAF 节流；气泡跟随 |
| SegmentedControl | 2–4 段 | 选中片 160ms 滑移动画（用于翻页方式等） |
| ThemeDots | 三圆 | 直径 28px；选中态外圈 2px primary 描边 + 勾 |
| BottomSheet | — | 圆角 20 顶角；下滑 120px 或点遮罩关闭；夜间用描边替代阴影 |
| Drawer | 左滑 | 宽 82%/380px；进入 280ms；支持边缘右滑关闭 |
| Toast | info / success | 底部上浮 240ms，3s 自动消失，同时最多 1 个（不排队，后来的顶掉前一个） |
| Dialog | 确认类 | 仅用于**删除书籍**等不可逆操作；文案写明后果（"同时删除书籍文件"） |
| EmptyState | — | 插画 + 一句主文案 + 一个主按钮，禁止堆说明文字 |
| Skeleton | — | 书架首载用封面形状骨架，300ms 后未出数据再显示（避免闪烁） |

**状态全覆盖要求**：以上每个组件规格必须包含 default / pressed / disabled / loading 四态中适用的部分；页面级必须有 loading（骨架）、empty（空状态）、error（友好文案 + 重试按钮）三态。对应 M5 验收的"损坏文件等 → 友好提示而非崩溃"。

### 4.1 图标规范（硬性规定）

> **禁止使用 emoji 充当图标，必须使用图标库图标。**（2026-10-09 用户确认，属于不可违反的硬性规定）
> 设计草图中如出现 emoji，均为早期占位；实现阶段一律替换为图标库图标。

| 项 | 规定 |
|---|---|
| 图标库 | **Lucide**（ISC 许可，无署名义务；shadcn/ui 官方默认，生态一致） |
| 风格 | 线性图标：24×24 网格、`stroke-width: 2`、圆角端点，全库统一，**禁止混用第二套图标库** |
| 封装 | 统一走 `<Icon>` 组件（`lucide-react`），**禁止手写内联 SVG path 散落在业务组件里** |
| 命名 | 与 Lucide 官方名一致（kebab-case），不自创别名 |
| 尺寸阶梯 | 16px（行内文字旁）/ 20px（按钮内）/ 24px（独立图标按钮内）；触控目标仍按 ≥ 44×44px |
| 颜色 | 一律 `currentColor` 继承父级文字色，**禁止给图标单独配色**；确需强调时改父级的文字令牌而非图标色 |
| 禁用项 | ❌ emoji 图标；❌ 填充式与线性混搭；❌ 第二图标库（Material / AntD Icons 等） |

常用图标映射（防临场乱选）：

| 功能 | 图标 | 功能 | 图标 |
|---|---|---|---|
| 目录 | `list` | 书签 | `bookmark` |
| 设置 | `sliders-horizontal` | 字号 | `type` |
| 常亮 | `sun` | 返回 | `chevron-left` |
| 导入 | `book-plus` | 网格视图 | `layout-grid` |
| 列表视图 | `list` | 重命名 | `pen-line` |
| 删除 | `trash-2` | 关闭 | `x` |
| 确认 | `check` | 搜索（2.0 预留） | `search` |

禁 emoji 的理由（写死，防将来翻案）：emoji 跨平台字形不一致（Windows / 安卓渲染差异极大）、无法随主题着色（夜间模式失控）、与线性 UI 图标风格天然冲突——三条对本项目"双端同源 + 三主题"的架构全是硬伤。

## 5. 手势与键盘（双端交互矩阵）

| 操作 | 手机/平板 | 桌面 |
|---|---|---|
| 上一页 / 下一页 | 点左右分区 / 右左滑 | ← → / PgUp PgDn / 空格下一页 |
| 呼出菜单 | 点中央 | 同左（保持一致，不引入右键菜单） |
| 加书签 | 长按 400ms | 长按或菜单按钮 |
| 调字号 | 双指捏合（M4） | Ctrl + 滚轮 |
| 关面板/抽屉 | 下滑 / 点遮罩 | Esc |
| 返回 | 系统返回键（阅读→书架→退出确认） | Esc 层级回退 |

> 双指捏合调字号、长按书签在 M4 交付（里程碑既定），设计规格现在定死，避免到时临场发明。

## 6. 无障碍与包容性（WCAG AA 基线）

| 项 | 规格 |
|---|---|
| 对比度 | 正文/按钮文字 ≥ 4.5:1（§2.2 已核对）；辅助文字允许 3:1（限大字号） |
| 触控目标 | ≥ 44×44px；三分区、滑杆轨道全部达标 |
| 焦点可见 | 桌面端 `:focus-visible` 2px primary 外描边（键盘导航必须可见） |
| 减弱动效 | `prefers-reduced-motion` 全局生效（§2.7） |
| 文字缩放 | 设置面板、书架支持系统字体缩放 200% 不破版 |
| 语义 | 菜单/抽屉/dialog 用 ARIA role；正文容器 `aria-live` 关闭（避免朗读器每页播报） |

## 8. 设计决策速查

| 问题 | 决策 | 一句话理由 |
|---|---|---|
| 品牌色 | 黛青 + 朱砂点缀 | 与"书卷气"自洽，与市面产品拉开 |
| 默认主题 | 纸黄 | 阅读器的第一印象应当是"纸"，不是"屏幕" |
| 正文默认字体 | 衬线（可选黑体） | 区分 UI 与内容；衬线是低成本高感知的"书感"来源 |
| 封面 | 书名 hash 生成占位封面 | TXT 无封面，灰块阵列是市面阅读器最丑的通病 |
| 点击分区 | 30/40/30 | 中央 40% 足够宽不易误触，两侧对翻页高频操作友好 |
| 翻页动画 | 平移 220ms + 跟手拖拽 | 仿真卷页成本极高（1.0 不做，见可行性 §1）；跟手的平移已显著优于固定动画 |
| 菜单形态 | 上下双条覆盖，不缩放正文 | 正文重排 = 阅读位置风险，覆盖层零风险 |
| 设置双层 | 阅读面板（每书）+ 全局页 | 与 IPC 契约 `ReaderSettings` 的"全局默认 + 每书覆盖"一一对应 |
| 夜间阴影 | 描边替代阴影 | 深色下阴影不可见，描边是唯一正确的层级表达 |
| 图标 | Lucide 图标库，**禁 emoji** | 跨平台字形一致、可随主题着色、与 shadcn/ui 生态同源（§4.1） |
