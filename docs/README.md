# 简阅 · PlainRead — 纯 Rust 跨端小说阅读器

> **一句话定位**：一套 Rust 代码，同时跑在 Windows 桌面、安卓手机、安卓平板上，只做一件事——干净地读小说。
> **1.0 范围**：仅支持导入 `.txt` 书籍。
> **工程代号**：PlainRead（仓库、包名、crate 名均以 `plainread` 为准）。

---

## 结论速览

| 维度 | 结论 |
|---|---|
| **可行性** | ✅ **可行**。1.0 所需的全部能力都有成熟方案支撑 |
| **跨端外壳** | **Tauri 2**（Windows / 安卓手机 / 安卓平板同一套代码） |
| **UI 技术** | **Web 技术栈**：HTML / CSS / TypeScript |
| **前端框架** | React + TS + Vite + Tailwind CSS + shadcn/ui（见 [ADR-004](adr/ADR-004-前端技术栈选型.md)） |
| **排版与分页** | **交给 WebView 引擎**：`line-break: strict`（CJK 禁则）、`text-spacing-trim`（标点挤压）、字体回退全自动 |
| **本地存储** | **redb**（纯 Rust，交叉编译零障碍）+ postcard 序列化 |
| **编码识别** | **chardetng + encoding_rs**（GBK / GB18030 / Big5 / UTF-8 / UTF-16 全覆盖） |
| **Rust 内核** | `reader-core`：领域模型 · 编码 · 切章 · 存储 · 导入管线（**与 UI 框架无关**） |
| **最大技术风险** | **WebView 版本碎片化**（老设备拿不到新 CSS 特性）；移动端插件生态相对薄 |
| **总体判断** | 无颠覆性障碍。原方案中「中文禁则」与「安卓安全区」两项高风险，已由 Web 平台天然消除 |

## 「纯净版」的工程含义

这个词在代码层面必须被翻译成可验收的约束，否则会变成一句口号：

1. **无广告、无账号、无网络请求** —— 1.0 不引入任何 HTTP 客户端依赖，可从依赖树审计。
2. **离线优先** —— 所有数据在本地，应用可断网完整运行。
3. **单一目标** —— 只读书，不做书城、不做社区、不做笔记体系。
4. **视觉极简** —— 四屏结构：书架 / 阅读 / 目录 / 设置。阅读页默认全屏沉浸，**零常驻控件**。
5. **不污染系统** —— 导入的书籍复制进应用私有目录，只向系统申请「用户主动选择的那一个文件」的读取权。
