# M1 人工导入测试语料

由 [gen-test-files.ps1](gen-test-files.ps1) 生成（幂等，可重复运行），对应
[03-里程碑与验收清单](../docs/03-里程碑与验收清单.md) M1 一节的验收标准。
语料字节敏感（GBK/GB18030/Big5/UTF-16LE），**不要用编辑器手工改生成物**；已通过 [.gitignore](.gitignore) 排除出版本库。

> 本机执行策略若拦未签名脚本，用：
> `powershell -NoProfile -ExecutionPolicy Bypass -File test-files/gen-test-files.ps1`
> （脚本须带 UTF-8 BOM，否则 PowerShell 5.1 会按 ANSI 读取导致中文全乱。）

## 文件清单 ↔ 验收项对照

### 一、编码系列（验收：GBK 老书无乱码 / 四种编码解码正确）

| 文件 | 说明 | 预期 |
|---|---|---|
| `编码-01-GBK老书-CRLF.txt` | GBK 编码、CRLF 换行，模拟十年前网文站下载 + 记事本转存 | 无乱码，`source_encoding` = GBK，换行被统一 |
| `编码-02-GB18030生僻字.txt` | 含 4 字节区生僻字 㐀 / 䶵 / 𠀀（GBK 编不了） | 生僻字不丢，`source_encoding` = GB18030（区别于 GBK） |
| `编码-03-Big5繁体.txt` | 繁体多章 | 繁体显示正确，不豆腐块 |
| `编码-04-UTF16LE-BOM.txt` | FF FE 开头，记事本"Unicode"格式 | 解码正确 |
| `编码-05-UTF8-BOM.txt` | EF BB BF 开头 | 解码正确，BOM 被剥掉 |

### 二、章节切分（验收：切分正确 / L4 兜底 / 误判保护）

| 文件 | 说明 | 预期 |
|---|---|---|
| `章节-06-混合标记风格.txt` | 楔子/第N章(中文数字)/第3章(阿拉伯)/第N回/Chapter 5/五、/尾声 混排 | **观察用**：看 L1/L2/L3 各策略实际行为，不设硬性断言 |
| `章节-07-无章节散文-L4兜底.txt` | 纯散文，无任何章节标记；含 "1937年"、"3.5 毫米"、"2026.1.1" 等 L2 数据陷阱 | 走 L4 兜底，`has_real_chapters == false`，书架有对应标识 |
| `章节-08-正文误判陷阱.txt` | 5 个真章节 + 3 行以"第一章/第二回/第三章"开头的正文句 | 章节数 = 5；陷阱行留在原文所在章节内，**不**成为新章节 |

### 三、边界样本（M1 不崩溃 + M5 预验收）

| 文件 | 说明 | 预期 |
|---|---|---|
| `边界-09-空文件.txt` | 0 字节 | 不崩溃，给友好提示 |
| `边界-10-单行无换行.txt` | 54 字节单行、无结尾换行 | 正常导入（L4 兜底） |
| `边界-11-全乱码.txt` | 128KB 随机字节（GBK/Big5 引导区混杂） | 编码识别失败 → 友好提示而非崩溃 |

### 四、重复导入对（验收：content_hash 命中 → "疑似重复"提示）

| 文件 | 说明 |
|---|---|
| `重复导入-12-原版.txt` | 两者**字节完全相同**（SHA256 一致），仅文件名不同 |
| `重复导入-13-改名重传版.txt` | 导入第二份时应触发 `import://duplicate` 事件 |

### 五、大体量（验收：10MB 导入界面不冻结、进度条实时推进、Rust 峰值内存增量 < 100MB）

| 文件 | 体量 | 章节数 | 用途 |
|---|---|---|---|
| `长篇-14-凡人修真录-UTF8.txt` | ≈ 9.8 MB | 1200 章（中文数字章号） | 主力性能样本；观察进度横幅、导入期间书架可交互、任务管理器看内存 |
| `长篇-15-星海征途-GBK.txt` | ≈ 9.8 MB（≈ 500 万字） | 1800 章（阿拉伯章号） | 大文件 × GBK 探测的组合压力 |
| `中篇-16-都市夜行手记-UTF16LE.txt` | ≈ 2.0 MB | 350 章 | UTF-16 解码在较大体量下的表现 |

内存验收建议：打开任务管理器 → 详细信息 → 加"提交大小"列，记录导入前 plainread 基线，
导入中观察峰值，峰值增量应 < 100 MB。

### 六、书架规模（验收：200 本规模滚动流畅）

`书架200本/` 下 200 份小书（每份 8 章、约 15KB，内容互不相同以免触发查重）。
导入方法：书架导入按钮 → 系统对话框里 **Ctrl+A 全选** 这 200 个文件 → 一次批量导入，
顺便验证批量导入的进度事件（`import://progress` 的 index/total 推进）。
导入完成后切列表/网格两种视图、滚动、删除若干本，观察流畅度与 redb/目录清理。

## 已知生成参数

- 全部语料由固定种子的 LCG 驱动，**每次重新生成字节一致**，可做回归对比。
- 段落为 3-5 句随机拼接，句池全部是 GBK 可编码的常用字（Big5 文件用单独繁体池）。
- 章节标题格式与 reader-core `chapterize.rs` 的 L1 规则对齐
  （`第N章/回/节/卷/部/篇/集` + `Chapter N`，标题行短且无句末标点）。
